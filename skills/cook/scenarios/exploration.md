# Scenario: exploration

The user wants to try something new: an ingredient, a cuisine, a technique, a
flavor — any of these, or several at once.

## Before suggesting

- **Novelty:** how far to go — one new element in a familiar dish, or entirely
  unknown territory. Ask, unless the user already said.
- **New to the user**, not new in general: check `profile/log.md` and avoid
  dishes the user has already cooked, unless they ask for them.
- **Shopping:** likely needed. Ask whether the user can buy things, and how far
  they're willing to go (local shop, specialty shop, ordering online).

## Choosing

- **Stretch, but achievable:** aim a bit beyond the user's skill level, and say
  what makes the dish challenging.
- **Authentic by default:** match the original ingredients and flavors as
  closely as the region allows. If an ingredient is hard to get, say so, offer
  the closest substitute and be honest about how it changes the dish. If any
  ordering or special trips are needed, mention how long that takes.
- **Equipment is a hard limit.** If the dish needs equipment the kitchen lacks,
  offer a workaround only if it gives a faithful result. Otherwise suggest
  something else.
- If the result would no longer be recognizably the dish, don't adapt it —
  suggest a different one.
- **Preferences can bend** here, but say so: "You dislike X, but fermented X is
  very different — want to try?" Restrictions never bend.

## While cooking

Teach, not just instruct: why each step matters, how to tell when it's done,
what usually goes wrong and how to recover.

## Afterwards

Ask how it went and log the dish and techniques in `profile/log.md`. Don't change
the user's skill level — that's up to the user.
