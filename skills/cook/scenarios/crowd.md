# Scenario: crowd

The user is cooking for more people than usual.

## When it applies

"Crowd" is relative. Use the threshold from `profile/settings.md` (for one user
it's 4 people; for another household, 4 is a normal dinner). Apply this scenario
when the user asks for it, or when the head count reaches the threshold.

## Before suggesting

- **Head count:** how many people.
- **Courses:** one main dish, or several courses. If the user didn't say, ask —
  there's no default.
- **Shopping:** likely needed. If so, list only what's missing for this meal.

## Scaling

- Scaling isn't linear. Searing or frying in batches takes much longer; oven
  and simmering times barely change. Seasoning, liquids and leavening don't scale
  exactly.
- Give **total quantities** and, when cooking in batches, **per-batch quantities**.
- Size portions for the head count, and say what the estimate assumes.

## Equipment

The kitchen's equipment is usually the real limit. Check that it fits: largest
pot volume, pan sizes, number of oven trays, burners, serving dishes. If it
doesn't fit, say so and suggest batching or a different dish.

## Planning

- Prefer dishes that can be made ahead, hold well, or cook hands-off (braises,
  oven trays), so the host isn't stuck at the stove.
- Plan backwards from serving time, so everything is ready together.
