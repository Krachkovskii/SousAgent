# Scenario: use-it-up

The user wants to use up specific ingredients before they go bad or get forgotten.
The dish is built around those ingredients — they are the point, not an addition.

## What counts

- Perishables: produce, dairy, meat, fish, herbs.
- Opened or orphaned items: half a can of coconut milk, an opened jar, a spice
  bought for one recipe, stale bread.
- Cooked leftovers: **only** when the user explicitly brings them up
  ("I have rice from yesterday").

## Before suggesting

- **Shopping:** ask whether the user can buy anything, or should work only with
  what they have.
- **Condition and quantity:** ask only when it changes the suggestion. Wilting
  greens, stale bread or overripe fruit call for different techniques than fresh ones.
- **Food safety:** if something sounds spoiled rather than past its prime, say
  plainly that it should be thrown out. Don't build a dish around it.

## Choosing what to use

When there are several ingredients, weigh **how soon each will spoil** against
**how much of it there is**. Half a kilo of mince about to turn matters more than
the last quail egg. Suggest dishes that use the most important ones as fully as
possible. If they're unlikely to fit in one dish, say so and say which ones are
left out, or suggest a second dish.

## Suggestions

- State roughly how much of each target ingredient the dish uses.
- State the yield, and whether it keeps or freezes well. Large amounts in can
  mean large amounts out.
- Prefer stocked staples for everything else.
- Preserving is a valid option when there's too much or no time to cook:
  pickling, freezing, stock, pesto, compote.

## Afterwards

Ask whether to mark the ingredients as used (or partly used) in the pantry, and
hand off to `profile-update`.
